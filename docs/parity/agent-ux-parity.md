# Agent UX Parity Matrix

The rule: a local agent, an SSH agent, and a hosted SSH agent look and behave the same in every surface. Only the transport differs:

| Mode   | Where the AI turn runs                                                         |
| ------ | ------------------------------------------------------------------------------ |
| Local  | A provider process that this Maestro spawns on this machine.                   |
| SSH    | This Maestro spawns the provider over SSH (`wrapSpawnWithSsh()`).              |
| Hosted | The Maestro host on the remote spawns it; this Maestro sends `federation:act`. |

The one permitted visual difference is the **mode pill**: one small `LOCAL`, `REMOTE`, or `HOSTED` pill, drawn by `AgentModePill` (`SessionList/AgentModePill.tsx`, over `FederationBadge`) with the same props in every place a mode is shown: the Left Bar row, the collapsed Left Bar's hover card, and the Main Window header. Its color and hover card carry the mode's state (the host's connection, a failed SSH run, a blocked automatic move). No other mark names the mode: no remote-name pill, no server icon, no separate transport badge. The `GIT` pill and the branch pill say only "git repository" and draw the same in every mode. Any other place where SSH or hosted takes its own UI branch is a defect. Fix it by collapsing to the same component and props, and route only the action through the transport.

## Legend

| Mark | Meaning                                                                                      |
| ---- | -------------------------------------------------------------------------------------------- |
| ✅   | Identical in all three modes, with a test that renders or runs each mode.                    |
| 🟢   | Same component and props in the code (read, no mode branch). A three-mode test is still due. |
| ❌   | Defect: a mode takes its own UI branch or loses behavior.                                    |
| 🔒   | Execution-only constraint that cannot be removed. The reason and the code path are given.    |
| ⏳   | Not audited yet.                                                                             |
