# v1.1.1-RC approved framing

Approved by Pedram on 2026-11-15. This file overrides "Picking the headline" in
[RELEASE-RUNBOOK.md](../RELEASE-RUNBOOK.md) for this release. See "Approved
framing" there.

## Title

`v1.1.1-RC | Night Shift`

## Highlights, in this order

1. 🌙 **Hosted agents keep working while your laptop sleeps** (Move to Host,
   built on Federation). The lead everywhere: notes, email subject, Discord, X.
2. 📌 **Pin the message you will want again** (Ctrl+Cmd+P).
3. 📊 **Dataview and DataviewJS for your Obsidian vault** (an Encore Feature).

The email, Discord, and X use only these three, in this order.

## Not highlights

These stay `Also in 1.1.1-RC` bullets. Do not promote them:

- 🗓️ The timeline ("the file I just saved").
- ↩️ Reopen Closed Tab survives a quit.
- 🧠 Long Claude Code turns are no longer cut off.

## Why

Pedram picked Move to Host as the lead and called it a very big deal. It scores low on the
rubric because only SSH users have it, and this is a deliberate override: it is
the release's defining change, and the title is about it. The rubric preferred
the timeline and Reopen Closed Tab; Pedram dropped both from the highlights.

## If v1.0.4 ships first

The notes open with "carries everything in stable 1.0.3". If v1.0.4 is
published before this tag, change that line to 1.0.4, and keep the 1.0.4
headlines (code editor, diff review comments, Design Mode) out of this
release's notes and announcement.
