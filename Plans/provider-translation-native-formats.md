# Claude Code and Codex native mapping

Implementation mapping, 2026-10-14. Claude Code **2.1.296**, Codex **0.162.1**. Both directions remain **unverified**. Schema inspection, structural readback and lint are not native resume evidence. No imports, tests or live acceptance cases were executed while implementing this feature.

## Transport and projection

`parseNativeLines` is shared by the native History readers and translation. History's flattened `SessionMessage.content` is never an import transport. `PortableRecord.native` retains each parsed row; a separate SHA-256 artifact retains the entire original file including malformed/unknown rows, whitespace and line endings.

| Class                | Claude Code source                                                       | Codex source                                                                            | Destination behavior or limitation                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Order and roles      | `user`/`assistant`, `message.content`, `uuid`, `parentUuid`              | `response_item` messages and legacy direct messages                                     | Ordered typed blocks; original roles/provenance archived; historical system/developer messages are not foreign instructions                                               |
| Identity             | Account root, session ID, row UUID                                       | Account root, thread ID, item ID; append-only line position where native IDs are absent | Original identity and checkpoints prevent import echoes; identical text with different IDs remains distinct                                                               |
| Tools                | `tool_use` ID/name/input; `tool_result.tool_use_id`, content, error flag | Function/custom tool call IDs, names, arguments and outputs                             | Tool history only; no execution or approval. Broken or unfinished linkage blocks                                                                                          |
| Assistant phases     | Native assistant message                                                 | `phase` on Responses messages                                                           | Codex phases projected; source-only execution state retained as evidence                                                                                                  |
| Images               | Typed image/source blocks                                                | `input_image`/`image` URLs/data                                                         | Valid inline user images archived/projected; unresolved external images block. Assistant images remain archive-only for Codex with an explicit warning. No invented bytes |
| Parent/branch        | Parent UUIDs, `isSidechain`, branch metadata                             | Native fork/branch metadata                                                             | Parent chains retained in portable data; foreign branch semantics warn. Claude sidechains are archived, excluded from the target's active conversation                    |
| Compaction           | Native compact boundary/metadata                                         | Native compaction/world-state records                                                   | Archived with explicit warning; no silent summary/truncation or fabricated foreign compact state                                                                          |
| Usage/model/cwd      | Native usage, model, session ID and cwd                                  | Session/turn metadata, token events, cwd                                                | Preserved as source evidence. Destination synthetic Claude rows use destination cwd and zero imported usage; historical billing is not new usage                          |
| UI projections       | Progress/status rows                                                     | `event_msg` display summaries duplicate Responses content                               | Archived; do not inject duplicate display text as additional model messages                                                                                               |
| Thinking/world state | Signed thinking, unknown blocks                                          | Encrypted reasoning, opaque native records                                              | Byte-preserved evidence; not re-signed, decrypted or replayed as foreign reasoning                                                                                        |
| Unknown/malformed    | Raw row                                                                  | Raw row                                                                                 | Unknown records warn and remain recoverable. Malformed rows, duplicate native IDs, root/session mismatch or edits/truncation block                                        |
| Maestro envelopes    | Existing embedded system prompt wrapper                                  | Same shared wire format                                                                 | Canonical envelope parser removes prior wrapper from foreign user content; original evidence and warning retained                                                         |

Extraction is native-format specific. The shared reconciler keys original provider/account/session/event identity and records generated native lineage. A return hop reads new native rows, unions new original records and reprojects a fresh session. It never appends text copied from Maestro's visible transcript. Previously parked destination sessions with new divergent work block rather than silently merge branches.

## Codex provider-supported mechanisms

Read-only schema generation used the installed CLI:

```bash
codex app-server generate-json-schema --experimental --out .maestro/scratch/provider-translation-schema
```

| Mechanism                    | Installed shape                                                                                                    | Use and limit                                                                                                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `externalAgentConfig/detect` | Optional `cwds`, `includeHome`, `migrationSource`, `source`, `maxSessions`, `maxSessionAgeDays`                    | Select repository cwds and disable home discovery; a detected account-wide item is not approval to import it                                                                   |
| `externalAgentConfig/import` | `migrationItems`; optional same `migrationSource`, attribution `providerId`/`source`                               | Shared utility accepts only explicit cwd-bound `MEMORY`, `SESSIONS`, `SKILLS`, `SUBAGENTS` selections; no config/hooks/MCP/plugins/credentials                                 |
| Selected details             | `memory: string[]`, `sessions: {cwd,path,title?}[]`, `skills: {name}[]`, `subagents: {name}[]`                     | Nonempty explicit selections required; exact project scope checked before request                                                                                              |
| Import completion            | Response `importId`; notification `externalAgentConfig/import/completed` with `itemTypeResults` successes/failures | Subscribe before request, match ID, await completion, reject per-artifact failures; timeout requires inspection before retry                                                   |
| Import histories             | `externalAgentConfig/importHistories/read` returns `data` and `connectors`                                         | Inspection/recovery evidence; not proof that the imported native thread resumes faithfully                                                                                     |
| `thread/start`               | Fresh thread, cwd, read-only sandbox, no approvals, `persistExtendedHistory`                                       | Primary destination path; retain returned ID/rollout path and journal ownership                                                                                                |
| `thread/inject_items`        | `threadId`, raw Responses `items`                                                                                  | Persist history without a generated turn. Readback must contain matching IDs and payloads; absent durable rollout blocks                                                       |
| `thread/items/list`          | `threadId`, optional cursor/limit/order/turn; result `data`, `nextCursor`, `backwardsCursor`                       | Shared ascending paginated reader detects repeated cursors. SQLite-backed ThreadItem projection is archived, but missing raw rollout/tool/reasoning evidence blocks conversion |
| `thread/resume.history`      | Unstable Codex Cloud override, marked DO NOT USE                                                                   | Excluded. No context-free `exec` fallback and no direct SQLite writes                                                                                                          |

The scoped importer is available for callers that can approve exact output ownership. The current primary migration uses explicit fresh-thread injection and managed resource projection because the importer does not prove return-trip lineage, output equivalence or safe rollback ownership. All schema-supported behaviors remain subject to later native acceptance. Sources: [App Server](https://learn.chatgpt.com/docs/app-server), [history injection](https://learn.chatgpt.com/docs/app-server#inject-items-into-a-thread), [Codex subagent configuration](https://learn.chatgpt.com/docs/agent-configuration/subagents).

## Native discovery and resources

| Resource                | Discovery contract                                                                                                 | Limits                                                                                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude project memory   | Effective account root, account/project/local `autoMemoryDirectory`, repository identity from Git common directory | Account override is shared user knowledge and needs explicit selection; session cwd remains separate from default memory repository identity                                 |
| Managed memory          | Operation-owned `.maestro/provider-knowledge/<agent-hash>/<operation-id>/memory` and linked topics                 | Shared per-launch index binding for both providers; Claude per-launch settings point at managed memory. Recall is unverified                                                 |
| Instructions            | Existing CLAUDE/AGENTS canonical body, relative alias when compatible                                              | Distinct bodies block. Do not inject the same instruction body again through the knowledge index                                                                             |
| Skills                  | Claude `.claude/skills`, Codex `.agents/skills`; retain scripts/resources and owner execute bit                    | Original frontmatter archived. Unsupported hooks/tool/fork/runtime metadata skips native installation of the whole skill; knowledge access is not equivalent skill execution |
| Subagents               | Claude Markdown/YAML frontmatter ↔ Codex `.codex/agents/*.toml`                                                    | Name/description/instructions projected with actual YAML/TOML parsers. Unsupported models/effort/memory/tool controls remain limitations; no permission broadening           |
| Selected user resources | Explicit files/subtrees within approved memory, skills, agents or instruction roots                                | No whole-account import, generated global memory summaries or provider databases. Directory links archived without implicit traversal                                        |

Resource return hops use the common baseline, native/managed variants and deletion tombstones. Conflicts retain both bodies and block. Existing unrelated native files are not overwritten; rollback touches only tracked unchanged output. Launch binding and Memory Viewer are the discovery interfaces, not a second editor or an account-global memory import.
